# Werkaholic AI Remake

Neuaufbau der App: Scanner → KI‑generierte Kleinanzeigen → Verlauf → Export.

Schnellstart

1. Clone:

```bash
git clone https://github.com/sschknn/werkaholic-ai-remake.git
cd werkaholic-ai-remake
```

2. Abhängigkeiten installieren:

```bash
npm install
```

3. Dev Server:

```bash
npm run dev
```

Um die Open Code API zu nutzen: setze den API‑Key lokal in der App (Settings) oder lege eine .env mit OPEN_CODE_API_URL fest.
